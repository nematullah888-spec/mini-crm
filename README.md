# برنامج العملاء (MiniCRM)

برنامج ويندوز بسيط لحفظ بيانات العملاء، بتصميم ويندوز الكلاسيكي، يشتغل **بدون إنترنت**:
- **جهاز واحد**: كل شيء على نفس الجهاز.
- **شبكة**: جهاز «خادم» يحفظ البيانات، وباقي الأجهزة «عملاء» يتصلون فيه عبر الشبكة المحلية.

**المميزات:** إضافة / تعديل / حذف العملاء، بحث سريع يفهم (أ/ا، ة/ه، ى/ي)، تصنيف العملاء، تصدير إلى Excel، تحديث تلقائي بين الأجهزة كل 3 ثوانٍ، رمز حماية للشبكة، ونسخة احتياطية تلقائية يومية (آخر 14 يوم).

**الاشتراكات (من الإصدار 1.1):**
- لكل عميل اشتراك لكل خدمة (مثل: مانجر، أورنيوم)، مع سجل كامل للتجديدات.
- عند الإضافة تختار الخدمة، وتاريخ البداية، والمدة (سنة / 6 أشهر / 3 أشهر / شهر / مدة أخرى)، والمبلغ.
- البرنامج يحسب الأيام المتبقية، ويلوّن العميل: 🟧 قرب الانتهاء، 🟥 منتهي.
- علامة **«أقل من سنة»** على أي اشتراك مدته أقل من سنة.
- 🔔 تنبيه عند فتح البرنامج بالعملاء اللي باقي على اشتراكهم 10 أيام أو أقل (تقدر تغيّر عدد الأيام وأسماء الخدمات من الإعدادات).
- زر **تجديد** يبدأ الاشتراك الجديد من تاريخ انتهاء القديم تلقائياً.

**الشكل (من الإصدار 1.2):** ثيمين تختار بينهم من **عرض** أو من **الإعدادات**:
- **كلاسيكي** — شكل ويندوز 98.
- **حديث** — شكل ويندوز 11.

كل جهاز يحفظ الشكل اللي اخترته.

**تسجيل الدخول (من الإصدار 1.3):**
- أول مرة تفتح البرنامج تسوي **اسم مستخدم وكلمة مرور وإيميل**، وبعدها ما أحد يدخل البرنامج غيرك.
- يطلع لك **رمز استرداد** (مثل `ABCD-EFGH-JKLM`) مرة وحدة: احفظه. يغيّر كلمة المرور **بدون إنترنت** إذا نسيتها.
- **نسيت كلمة المرور؟** يوصلك رمز من 6 أرقام على إيميلك (يحتاج إنترنت + إعداد الإيميل مرة وحدة).
- قائمة **الحساب**: تغيير كلمة المرور والبيانات، إعداد الإيميل، رمز استرداد جديد، تسجيل الخروج.
- 5 محاولات خاطئة = قفل دقيقة. كلمة المرور محفوظة مشفّرة.
- في الشبكة: كل الأجهزة تدخل بنفس الحساب (الحساب محفوظ على جهاز الخادم).

**إعداد الإيميل للاستعادة (مرة وحدة):**
1. في حساب Google فعّل **التحقق بخطوتين**.
2. ادخل [صفحة كلمات مرور التطبيقات](https://myaccount.google.com/apppasswords) وسوّ كلمة مرور جديدة (16 حرف).
3. في البرنامج: **الحساب ← إعداد الإيميل لاستعادة كلمة المرور** ← اكتب الإيميل وكلمة مرور التطبيق ← **حفظ وإرسال تجربة**.

## الخطوة 1: رفع البرنامج على GitHub (مرة وحدة)

1. ادخل [github.com](https://github.com) وسجّل حساب (مجاني).
2. اضغط **+** أعلى الصفحة ← **New repository** ← الاسم: `mini-crm` ← اختر **Public** ← **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file**.
4. فك ضغط ملف `mini-crm.zip` على جهازك، وافتح المجلد، واسحب **كل محتوياته** إلى صفحة GitHub، ثم اضغط **Commit changes**.
5. تأكد أن الملف `.github/workflows/build.yml` موجود في المستودع.
   إذا ما انرفع: اضغط **Add file ← Create new file**، واكتب الاسم `.github/workflows/build.yml` بالضبط، والصق محتوى الملف، ثم **Commit**.

## الخطوة 2: GitHub يبني ملف التثبيت تلقائياً

- افتح تبويب **Actions**: بتشوف عملية البناء شغالة (تاخذ تقريباً 5 دقائق).
- إذا صارت علامة ✅ خضراء، ادخل **Releases** (يمين صفحة المستودع) وحمّل **MiniCRM-Setup.exe**.
- رابط التحميل المباشر دائماً:
  `https://github.com/اسم-حسابك/mini-crm/releases/latest/download/MiniCRM-Setup.exe`

## الخطوة 3: التثبيت

- شغّل `MiniCRM-Setup.exe` ← التالي ← تثبيت.
- البرنامج غير موقّع رقمياً، فقد يظهر تنبيه **Windows protected your PC**: اضغط **More info** ثم **Run anyway**.
- يظهر اختصار **برنامج العملاء** على سطح المكتب.

## تشغيل البرنامج على الشبكة

**في جهاز الخادم (الجهاز الرئيسي):**
1. افتح البرنامج ← **الإعدادات** ← اختر **خادم (سيرفر)**.
2. (اختياري) اكتب **رمز الشبكة** ← **حفظ وتطبيق**.
3. إذا ظهرت رسالة جدار حماية ويندوز، اضغط **السماح بالوصول** (Allow access).
4. سجّل العنوان الظاهر، مثل `192.168.1.20`.

**في كل جهاز ثاني:**
1. ثبّت البرنامج ← **الإعدادات** ← اختر **عميل**.
2. اكتب عنوان جهاز الخادم، ونفس المنفذ، ونفس رمز الشبكة.
3. اضغط **اختبار الاتصال**، ثم **حفظ وتطبيق**.

> مهم: جهاز الخادم لازم يكون شغّال والبرنامج مفتوح عليه، وكل الأجهزة على نفس الشبكة (نفس الراوتر).
> يُفضّل تثبيت عنوان IP لجهاز الخادم من إعدادات الراوتر حتى لا يتغير.

**إذا ما اتصل الجهاز:** تأكد من العنوان، وجرّب إيقاف جدار الحماية مؤقتاً للتأكد، أو اسمح للمنفذ `5055` في جدار حماية ويندوز.

## مكان البيانات والنسخ الاحتياطي

- البيانات: `%APPDATA%\MiniCRM\data\customers.json` (من البرنامج: **ملف ← فتح مجلد البيانات**).
- النسخ الاحتياطية اليومية: داخل مجلد `backups` في نفس المكان.
- إلغاء تثبيت البرنامج **لا يحذف** البيانات.

## تحديث البرنامج لاحقاً

عدّل الملفات على GitHub (وغيّر رقم `version` في `package.json`)، وسيبني GitHub نسخة جديدة تلقائياً في نفس رابط التحميل. ثبّت النسخة الجديدة فوق القديمة، والبيانات تبقى كما هي.

## للمطوّرين

```bash
npm install
npm start        # تشغيل البرنامج
npm test         # اختبار الخادم
npm run dist     # بناء ملف التثبيت على ويندوز
```
